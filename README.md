## ⚡ Descripción del Proyecto

**RutinaMaster 4000 (El Generador-de-Rutinas-Inador 3000)** es la aplicación web definitiva para generar **rutinas de gimnasio personalizadas y biomecánicamente óptimas**, ambientada en el universo cómico y melodramático del **Dr. Heinz Doofenshmirtz** (*Phineas y Ferb*).

La aplicación es **100% client-side (Zero-Backend, Zero-Cost)**, ultrarrápida, interactiva y con persistencia automática en el almacenamiento local del navegador (`localStorage`).

---

## 🚀 Características Principales

### 1. 🎯 Selector de Objetivo Corporal ("Target Zone Illumination-inator")
* Mapa corporal anatómico interactivo en SVG con vista Frontal y Dorsal.
* Iluminación reactiva en verde ácido de las zonas musculares seleccionadas (Pectoral, Espalda Alta, Espalda Baja, Hombros, Cuádriceps, Glúteos, Isquiotibiales, Bíceps, Tríceps, Core, Pantorrillas).
* Comentarios de voz reactivos de Heinz con quejas de su infancia en Gimmelshtump y su rivalidad con Roger.
* Presets rápidos: *Cuerpo Completo de Conquista*, *Torso Destructor*, *Piernas de Titán*, *Brazos & Blindaje*.

### 2. 🎛️ Calibrador de Logística y Esfuerzo
* **Frecuencia Semanal:** 2 a 6 días por semana con división inteligente (Full Body A/B, Push/Pull/Legs, Torso/Pierna).
* **Nivel de Experiencia:** Novato, Intermedio, Avanzado (calibra series, repeticiones RPE/RIR y descansos).
* **Entorno:** Gimnasio Comercial Completo vs. Sótano Casero con Mancuernas y Rencor.

### 3. ⚙️ Compil-inador Cuántico Animado
* Pantalla de carga con engranajes giratorios, diales, indicadores analógicos y frases aleatorias cambiantes de Heinz Doofenshmirtz.

### 4. 📋 Plano de Entrenamiento (Blueprint) & Algoritmo Biomecánico
* Bautizo automático de cada rutina como un **"-inador"** personalizado (ej. *El Pectoral-y-Glúteo-Destructor-Inador 4000*).
* Subtítulos hilarantes y consejos técnicos de Doof para cada ejercicio.
* **Lógica A: "¡Polea/Máquina Ocupada! Sustitución Rápida"** -> Reemplaza instantáneamente el ejercicio por un equivalente directo con mismo patrón de movimiento y curva de fuerza.
* **Lógica B: "No tengo esta máquina / No me gusta este ejercicio"** -> Reemplaza permanentemente en el plano por una variante de peso libre o alternativa biomecánica viable.
* **Control de Series:** Interruptores interactivos para marcar series completadas durante el entrenamiento.
* **Notas de Carga:** Campo para registrar pesos, repeticiones y sensaciones.
* **Exportación & Impresión:** Formato optimizado para imprimir (`@media print`) o copiar texto formateado al portapapeles.

### 5. 💥 ¡Botón de Autodestrucción!
* Modal de advertencia industrial con franjas de peligro y sirena sonora.
* Animación de sacudida de pantalla, explosión de partículas y reseteo total de datos.

### 6. 🦆 Easter Egg: Perry el Ornitorrinco
* Botón secreto con sombrero fedora que activa el informe confidencial de la O.W.C.A. y sonido característico.

### 7. 🔊 Síntesis de Sonido Web Audio API (Zero Dependencias Externas)
* Motor de audio nativo con el jingle de Doofenshmirtz Evil Inc., lásers, clics mecánicos, sirenas y explosiones sin necesidad de archivos MP3 externos.

## 📦 Instalación y Ejecución Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/JoseFerVG/rutinaMaster4000.git

# 2. Entrar en la carpeta del proyecto
cd rutinaMaster4000

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo
npm run dev

# 5. Compilar para producción
npm run build
```

## 🚀 Despliegue en 1 Clic (Vercel / Cloudflare Pages / GitHub Pages)

El proyecto está configurado para desplegarse instantáneamente en cualquier plataforma estática con soporte SPA gracias al archivo `vercel.json`:
